title: 'Workflows'
weight: 1
---

A workflow is a saved sequence of **blocks**. It can run code in seven languages, call saved HTTP endpoints and MCP tools, ask an AI model, branch, and loop. You can start it by hand or with a trigger. Each workflow is one YAML file, and each run gets its own folder.

The course runs in order from Stage 0 to Stage 10. Each stage is a section in the sidebar, and each lesson takes 5–20 minutes.
