By default, blocks run **top to bottom in file order**. This stage shows you four ways to change that order:

- **Decision**: choose one route.
- **Loop**: repeat a frame of blocks.
- **`then`**: jump to a named block, or to `break` or `continue` inside a loop.
- **Node execution off** (`enabled: false`): skip a block without deleting it.
