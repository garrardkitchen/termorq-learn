{{% callout style="goal" %}}
Return `ok` (on its own, or with other properties) correctly in every language. **Time:** 5 minutes.
{{% /callout %}}

`ok` is an ordinary boolean property, but it's an important convention. Shell blocks generated by [session capture](/workflows/capture-and-share/session-capture/) always end by printing `{"ok":true}` and declare `ok: boolean`. The editor's insertable examples include **Return a successful result** and **Return ok and a property** for every language.

If a block declares `ok`, the last line must include it as a **boolean**. The string `"true"` fails.

```yaml
outputs:
  type: object
  properties:
    ok: { type: boolean }
    summary: { type: string }
```

{{< tabs groupid="lang" >}}
{{% tab title="Bash" %}}
```bash
summary="3 files cleaned"
# jq -c keeps it on one line and escapes the string safely
jq -nc --arg summary "$summary" '{ok: true, summary: $summary}'
```
{{% /tab %}}
{{% tab title="PowerShell" %}}
```powershell
$summary = '3 files cleaned'
@{ ok = $true; summary = $summary } | ConvertTo-Json -Compress
```
{{% /tab %}}
{{% tab title="Python" %}}
```python
import json
print(json.dumps({"ok": True, "summary": "3 files cleaned"}, separators=(",", ":")))
```
{{% /tab %}}
{{% tab title="C#" %}}
```csharp
using System.Text.Json.Nodes;
Console.WriteLine(new JsonObject { ["ok"] = true, ["summary"] = "3 files cleaned" }.ToJsonString());
```
{{% /tab %}}
{{% tab title="Rust" %}}
```rust
fn main() {
    // No JSON library without Cargo: only safe when summary has no quotes, backslashes, or newlines.
    let summary = "3 files cleaned";
    println!("{{\"ok\":true,\"summary\":\"{}\"}}", summary);
}
```
{{% /tab %}}
{{% tab title="JavaScript" %}}
```javascript
console.log(JSON.stringify({ ok: true, summary: "3 files cleaned" }));
```
{{% /tab %}}
{{% tab title="TypeScript" %}}
```typescript
const result: { ok: boolean; summary: string } = { ok: true, summary: "3 files cleaned" };
console.log(JSON.stringify(result));
```

{{% callout style="tip" %}}
**Command Prompt** isn't one of the workflow languages. To run a `cmd.exe` command, use a PowerShell block with the editor's **Run a Command Prompt command** example. It runs the command through `%ComSpec%` and exits with the command's failure code.
{{% /callout %}}

{{% callout style="checkrun" %}}
Each variant publishes `ok: true` and `summary: "3 files cleaned"`.
{{% /callout %}}

{{% callout style="exercise" %}}
Make the Bash version publish `ok: false` when a directory called `logs` doesn't exist in the run's working directory, *without* failing the block.
{{% /callout %}}

{{% details title="Solution" %}}
```bash
if [ -d logs ]; then ok=true; else ok=false; fi
jq -nc --argjson ok "$ok" '{ok: $ok, summary: "checked logs"}'
```
The script exits with 0, so the block passes. A later Decision can then branch on `steps.<id>.ok == true`.
{{% /details %}}
