# Security policy

This repository contains documentation only. It has no runtime code.

- **Termorq product vulnerabilities:** follow the security policy in [garrardkitchen/ai-terminal](https://github.com/garrardkitchen/ai-terminal/security/policy). Don't open a public issue.
- **Problems with this site** (for example, a lesson that recommends an unsafe practice, or a leaked credential in an example): open a [private security advisory](https://github.com/garrardkitchen/termorq-learn/security/advisories/new) on this repository.

Examples must never contain real secrets, API keys, hook keys, or bot tokens. Use `secrets:` names and placeholders such as `<paste the key>`.
